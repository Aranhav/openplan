# M2 Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The in-memory calculation engine (`crates/engine`) with Anaplan-compatible lists, time, versions, modules, line items, formula language and incremental recalculation, plus server integration: persistence, per-model actors and the structure/cells/formula APIs.

**Architecture:** `crates/engine` is pure synchronous Rust. Structure is plain data; each line item owns a typed column (`Arc<Column>`, copy-on-write). Formulas compile to an expression tree evaluated in **batches of target cell indices** (vectorized per node), so the same evaluator serves full recalcs, partial (dirty-cell) recalcs, summary-level evaluation and period-by-period evaluation of time-shift cycles. Summaries are computed on demand into cached aggregated columns. The server wraps each loaded model in a `ModelActor` (tokio task) that applies command batches, persists them to an append-only change log, and publishes events.

**Tech Stack:** Rust 2024; engine deps: `uuid`, `serde`, `serde_json`, `thiserror`, `chrono`, `rayon`, `smallvec`, `zstd`; dev: `proptest`, `criterion`. Server: existing axum/sqlx stack, `tokio::sync::{mpsc, broadcast, oneshot}`, `dashmap`.

**Spec:** `docs/superpowers/specs/2026-10-15-openplan-design.md` §3, §4, §5, §6, §7 (structure/formula/data rows), §12, §13.

## Global Constraints

- All M1 Global Constraints apply (`docs/superpowers/plans/2026-10-15-m1-foundation.md`): crate versions, problem+json errors, snake_case JSON, UUID v7, no `query!` macros, no commented/unused code, commit trailers.
- `crates/engine` has **no** async, I/O, logging or database dependencies. Its public API is only what this plan names in Interfaces blocks.
- Anaplan semantics (spec §4.6): division by zero → 0; blank number = 0; blank boolean = FALSE; blank text = ""; `PREVIOUS`/`OFFSET` beyond the timeline → 0 or given default; numbers are f64; display rounding never applied in calculation.
- Base time granularity is month. Month index 0 = first month of fiscal year `first_year`. Fiscal year label `FYxx` uses the calendar year in which the fiscal year **ends** (start month 1 → FY26 = Jan–Dec 2026; start month 4, first_year 2026 → FY27 = Apr 2026–Mar 2027).
- Period labels (exact): month `"Jan 26"` (3-letter English month + 2-digit year of that month), quarter `"Q1 FY26"`, half-year `"H1 FY26"`, year `"FY26"`, all periods `"Total"`.
- Performance targets enforced by benchmark in Task E10: one input edit in a 1M-cell model recalculates dependents in < 50 ms; loading 10M input cells from encoded chunks + full recalc < 5 s (release build).
- Error codes (engine `code()` strings, mapped 1:1 to API problem codes): `formula.syntax`, `formula.unknown_name`, `formula.unknown_function`, `formula.arity`, `formula.type_mismatch`, `formula.dimension`, `formula.ambiguous_name`, `formula.cycle`, `structure.not_found`, `structure.name_taken`, `structure.invalid`, `structure.in_use`, `cells.invalid_value`, `cells.not_input`, `cells.invalid_coordinate`, `cells.locked`, `model.production_locked`.

## Review Focus

1. Deleting a list item or list that is referenced (as a module axis, a list-formatted value, a `SELECT`, or a mapping) → structural deletes of a list used as an axis are rejected with `structure.in_use` naming the modules; deleting items blanks list-formatted cells pointing at them and drops their cells, and formulas that `SELECT` a deleted item fail to compile with `formula.unknown_name` and the line item is marked in error (values blank) instead of crashing. Pinned in Tasks E2 and E9.
2. Formula names that collide with keywords or contain operators (`'Profit & Loss'`, a line item called `Margin %`, a line item named `IF Flag`) → quoted names resolve; unquoted keyword-led names give a `formula.syntax` error with a "quote the name" hint. Pinned in Task E4.
3. A batch of cell edits where one value is invalid or targets a calculated line item → the whole batch is rejected atomically with the offending cells listed; no partial write and no change-log row. Pinned in Tasks E2 and S5.
4. Server restart mid-session → model reloads to exactly the same input values and calculated results (checkpoint + replay), including edits made after the last checkpoint. Pinned in Task S1.
5. Fiscal year starting mid-year (start month 4) and line items at Quarter/Year time scale → period labels, quarter membership and YEARVALUE/TIMESUM results follow fiscal (not calendar) boundaries. Pinned in Tasks E1 and E8.
